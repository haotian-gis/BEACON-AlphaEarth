# Notebooks

The research pipeline is organized into three English-language notebooks:

1. `01_data_preparation.ipynb`: tri-modal input preparation and Earth Engine exports
2. `02_model_training.ipynb`: BEACON contrastive training and regional inference
3. `03_downstream_tasks.ipynb`: common-support downstream evaluation

All notebook outputs and execution counts are cleared. Paths and account-specific values are read from environment variables. External-service and cloud-export sections are disabled by default.
